## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
*   Node.js (v14.0.0 or higher recommended)
*   npm or yarn package manager
*   Firebase CLI (if deploying or using emulators locally)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/REEEEZEEEE/Velvet-Jack.git
   ```

2. Navigate into the project directory
   ```bash
   cd Velvet-Jack
   ```

3. Install NPM packages
   ```bash
   npm install
   # or
   yarn install
   ```

4. Set up environment variables
   Create a `.env` file in the root directory and add your specific configuration (e.g., Firebase config keys).
   ```text
   REACT_APP_FIREBASE_API_KEY=your_api_key
   REACT_APP_FIREBASE_AUTH_DOMAIN=velvet-jack.firebaseapp.com
   REACT_APP_FIREBASE_PROJECT_ID=velvet-jack
   ```

5. Run the development server
   ```bash
   npm start
   # or
   yarn start
   ```

## Deployment

This project is configured for deployment on Firebase Hosting. To deploy updates:

1. Ensure you are logged into the Firebase CLI
   ```bash
   firebase login
   ```

2. Build the production application
   ```bash
   npm run build
   # or
   yarn build
   ```

3. Deploy to Firebase
   ```bash
   firebase deploy
   ```
